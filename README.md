## 🌌 Особенности проекта

### 1. 🎯 Высокоточный DSP Тюнер
* **Алгоритм McLeod Pitch Method (MPM / NSDF)** — автокорреляционная нормализованная функция с параболической суб-интерполяцией пика, обеспечивающая суб-центовую точность ($\le 0.5$¢) в диапазоне от $B_0$ (30.8 Гц) до $B_5$ (987.7 Гц).
* **Нелинейная шкала центов** — 50% шкалы выделено под диапазон $\pm 10$ центов для сверхточного визуального контроля.
* **Динамическая аура** — световой ореол ноты, меняющий цвет от бирюзового (`В строе`) до янтарного (`Близко`) и мадженты (`Не в строе`).
* **Команды действия и указания направления колка** — `ПОДТЯНУТЬ` (вращение ↺) / `ОСЛАБИТЬ` (вращение ↻) с подсказкой устранения люфта («Подходите к ноте снизу»).
* **Режим Мастера (Auto-Advance)** — автоматическое переключение на следующую струну при фиксации строя на 1.2 секунды с виброоткликом (Haptic Feedback).
* **Спектрограмма гармоник** — отображение частотного спектра в реальном времени.

### 2. 🎼 Интерактивный SVG Гриф (Fretboard)
* **Физически точные лады** — расчет координат по формуле мензуры $d(n) = L \cdot (1 - 2^{-n/12})$ с четкими хромированными металлическими ладовыми порожками и объемными тенями.
* **Режим «Исследование»** — физический синтез щипка струны алгоритмом **Карплуса-Стронга (Karplus-Strong)** и обратное распознавание аккордов.
* **Режим «Гаммы»** — 15 ладов и гамм (мажор, минор, пентатоники, блюз, дорийский, фригийский, миксолидийский и др.) с отображением нот или ступеней ($1, \flat 3, 5$).
* **Режим «Аккорды»** — наглядные аппликатуры с позициями пальцев.
* **Экспорт в SVG & Deep Linking** — скачивание векторной схемы в один клик и сохранение состояния через хэш в URL.
* **Каподастр и леворукий режим** — поддержка гитар для левшей и смещение тона каподастром (1–7 лады).

### 3. 🔍 Контроль строя аккорда (Chord Check)
* **Векторная схема аккорда (Chord Diagram)** — наглядная аппликатура аккордового бокса с номерами ладов, точками зажатия, открытыми (O) и глушеными (X) струнами и кнопкой прослушивания перебором.
* **Режим A (Арпеджио)** — понотный перебор с проверкой чистоты звучания каждой зажатой струны.
* **Режим B (Спектральный анализ удара)** — распознавание всех струн аккорда за 1.2 с с учетом коэффициентов ангармонизма струн:
  $$f_h = h \cdot F_0 \cdot \sqrt{1 + B \cdot h^2}$$
* **Быстрый переход «Настроить»** — автоматическая фиксация проблемной струны в тюнере.

### 4. 🥁 Метроном & Акустические барабанные ритмы
* **Точный Web Audio метроном** с акцентированной первой долей и размерами 2/4, 3/4, 4/4, 6/4.
* **Акустическая драм-машина (Drum Synthesizer)** для живых репетиций:
  * 🎸 **Classic Rock** (прямой 4/4 с малым на 2 и 4)
  * 🎷 **Blues Shuffle** (триольный блюзовый свинг)
  * 🌴 **Bossa Nova** (латиноамериканский ритм с синкопированным римшотом)
  * 🕺 **Funk Groove** (качающие 16-е доли и синкопированная бочка)
* 16-шаговый визуальный секвенсор и функция **Tap-Tempo**.

### 5. 🎮 Тренажер музыкального слуха (Ear Training)
* **Режим «Ноты»** — определение ноты на слух по гитарному звучанию.
* **Режим «Струны»** — развитие распознавания открытых струн инструмента.
* **Режим «Мажор / Минор»** — определение ладовой окраски и характера аккорда.
* Накопление очков, учет серии побед (Streak 🔥) и персональные рекорды.

### 6. ⚙️ Гибкие настройки и строи
* 17 предустановленных строев: Standard E, Drop D, Drop C, DADGAD, Open D/G/C/E, 7-string, 12-string, Bass 4/5, Ukulele.
* **Конструктор пользовательских строёв** (от 4 до 8 струн) с сохранением в `localStorage`.
* Регулировка эталона $A_4$ (415–466 Гц, включая 432 Гц).
* Системы нотации: Английская ($C, D, E$), Немецкая ($C, D, H$), Сольфеджио ($До, Ре, Ми$).
* Темы оформления: «Ночь (Индиго)» и «День (Светлая)».

## 🛠️ Стек технологий

* **Frontend**: React 19, TypeScript, Vite
* **Аудио & DSP**: Web Audio API, McLeod Pitch Method (NSDF), Karplus-Strong Synthesis, FFT Analyzer, Drum Synthesizer
* **Графика & UI**: Векторный SVG, Lucide Icons, CSS Custom Properties (Design Tokens)
* **PWA**: Service Worker Network-First, Web App Manifest
* **Тестирование**: Vitest, Playwright

## 🚀 Запуск, сборка и деплой

### Установка зависимостей
```bash
npm install
```

### Запуск сервера разработки
```bash
npm run dev
```

### Запуск тестов
```bash
npm test
```

### Запуск E2E-тестов
```bash
npm run test:e2e
```

Подробности — в [tests/e2e/README.md](tests/e2e/README.md).

### Продакшн-сборка
```bash
npm run build
```

Подробное пошаговое руководство по деплою на Linux VPS (Caddy, Nginx) доступно в файле [DEPLOYMENT.md](DEPLOYMENT.md).
